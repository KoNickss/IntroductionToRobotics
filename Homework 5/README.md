# Homework 5 - Timer stopping accuracy game

At boot it displays the target number

Constrols:
 - UP: start (when displaying target number)
 - Joy click: STOP
 - DOWN: reset after stopping
 - LEFT: show high score (when displaying target number)
 
After stopping, the screen will show the error between stop time and target (eg. "E. 42") when there is an E, the screen is showing the error/difference/offset, either as a result of current game or high score. If the error is comically large, it will not show the error or save it as a high score, but rather show 4 lines ---- representing FAILURE.
